# Annuals ID — HORT 1230 Quiz 2

A mobile-friendly photo identification game for the 15 annuals in the supplied HORT 1230 Quiz 2 list. Enter the common and scientific names; each is worth half a point. Pronunciation cues from the course guide appear after answering. Every plant appears once per shuffled deck.

Includes both marigolds as separate entries. Dusty miller accepts Senecio cineraria or Jacobaea maritima. Angelonia accepts the document's spelling as well as the corrected angustifolia. Scientific-name aliases cover the garden verbena and petunia taxonomic names and typed x/× hybrid notation. Victoria Blue requires the cultivar name.

Live iNaturalist photos require internet access. Cultivated observations are included. Victoria Blue photos are species-level, and million bells photos are genus-level; exact cultivar/hybrid identity is not guaranteed. These limitations are disclosed in the game and after the relevant answers.

Serve this directory with a static HTTP server, or host it on GitHub Pages. No build step is needed. See README.txt for iPhone setup.
